# 🎬 Netflix Clone

Clone da plataforma Netflix construído com React + Vite + TMDB API

## 🚀 Tecnologias
- React 18
- Tailwind CSS 3
- Axios
- React Router DOM
- TMDB API

## ✨ Features
- 🎥 8+ categorias de filmes/séries
- 🔍 Sistema de busca
- ⭐ Lista de favoritos
- 📱 100% Responsivo
- ♾️ Infinite Scroll
- 🎬 Modal com trailers do YouTube
- ⚡ Loading skeletons
